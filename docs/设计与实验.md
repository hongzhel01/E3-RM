# E3-RM 设计与实验

E3-RM（E3-Inspired Progressive Reward Modeling）研究渐进式语义鲁棒奖励建模。当前完成的是训练框架精简和命名迁移，E3 专属损失、数据管线与实验仍待实现。

## 目标与现有能力

项目借鉴 E3CoverNet 的渐进式建模思想，分别学习语义保持变化的不变性，以及关键语义变化的敏感性。这里迁移的是思想，不引入三维几何网络，也不预先宣称实验有效。

保留 Reward、SFT、DPO、KTO、GRPO、RLOO、Distillation 七种训练器，以及其生成、奖励函数、PEFT/量化和分布式支持。原始 `RewardTrainer` 是奖励基线，后续 `E3RewardTrainer` 放入 `e3_rm/e3/`，不改写其他标准方法的目标。

## 三个训练阶段

1. **基础偏好排序**：使用同一问题的 chosen/rejected 回答，保持原有判别能力。
2. **表面与结构不变性**：只对已验证的等价格式或措辞改写约束奖励与偏好差值。
3. **关键语义敏感性**：事实反转、关键条件遗漏或指令违背使用独立排序标签，避免把错误回答当作等价扰动。

格式敏感任务中的格式变化、增加长度或无意义装饰均不能自动判为语义保持。变换应保留来源、验证状态和适用任务条件。

## 损失定义

令 `r_w`、`r_l` 为 chosen/rejected 奖励，`r'_w`、`r'_l` 为其等价变体奖励：

```text
L_pref   = mean(-log(sigmoid(r_w - r_l)))
L_inv    = mean((r(x, y) - r(x, T(y)))²)
L_margin = mean(((r_w - r_l) - (r'_w - r'_l))²)
L_sem    = mean(max(0, m - s × (r_a - r_b)))
L        = L_pref + λ_inv L_inv + λ_margin L_margin + λ_sem L_sem
```

`s ∈ {-1, +1}` 来自语义变化对的实际偏好标签，`m` 是最小排序间隔。各附加项仅在有效关系上求均值；不存在有效关系的批次不构造伪样本。`L_pref` 始终保留，其他权重按阶段引入并随 checkpoint 恢复。

当前源码仅有标准奖励模型的 Bradley–Terry 目标、可选 margin 与中心化约束，上述三个 E3 附加项尚未实现。

## 数据与实现约束

- 先按原始问题或来源分组划分训练、验证和测试，再生成变体，同源样本不得跨划分。
- 在原始 prompt/chosen/rejected 之外记录来源 ID、变换类型、验证结果和语义变化的排序方向。
- 专用分词和 collator 需保留新增列、有效关系 mask、批次索引，不能继续把所有奖励简单均分为 chosen/rejected 两半。
- 标签和元数据由训练器消费，仅向模型传递合法 forward 参数。
- 当前 `max_length` 会过滤超长偏好对；加入变体后需要同时报告筛选规则与有效覆盖率。
- LoRA/QLoRA 训练标量奖励模型时须保留 `score` 评分头的训练与保存；适配器重载需单独验证。

## 模型与实验

先使用 `Qwen/Qwen2.5-7B-Instruct` 验证方法、消融和参数，再扩展至 `Qwen/Qwen2.5-14B-Instruct`。采用 LoRA/QLoRA 时明确基座版本、量化、评分头初始化和精度。

| 实验 | 设置 |
| --- | --- |
| A | 原始 RewardTrainer |
| B | 基线 + L_inv |
| C | 基线 + L_margin |
| D | 基线 + L_sem |
| E | 完整渐进式 E3-RM |

固定数据划分、基础模型、样本过滤规则和比较预算，至少运行三个独立随机种子，报告均值和标准差。使用验证集选模型，测试集只用于最终报告；额外变体带来的 token 数、耗时和显存开销单独记录。

| 指标 | 统计口径 |
| --- | --- |
| Preference Accuracy | 原始测试偏好对中 chosen 奖励严格更高的比例 |
| Perturbation Flip Rate | 等价变换前后奖励差的符号变化比例，明确零差值规则和有效分母 |
| Reward Drift | 有效等价关系的绝对奖励变化均值，同时报告奖励尺度 |
| Semantic Sensitivity Accuracy | 有标签语义变化对满足 `s × (r_a - r_b) > 0` 的比例，并按变化类型分组 |

多卡统计聚合有效样本的和与计数，去除补齐产生的重复项，不能简单平均各卡百分比。训练 loss 降低、奖励差变大或改包名均不是方法有效的证据。
