# E3-RM 设计与实验

## 结论与适用范围

已完成 70,224 参数随机初始化 GPT-2 的 CPU 受控消融实验：完整 E3 在本任务上同时改善偏好排序、格式鲁棒性与语义判别。但渐进训练并未在所有指标上超过同时训练，指令违背子类仍有明显的随机种子差异。不能据此宣称真实大模型的 Reward Hacking 已解决。

四项目标的公式与数据格式见 [README](../README.md)，实现见 [e3_rm/e3](../e3_rm/e3/)，逐种子原始结果与数据指纹见 [tiny_ablation_results.json](tiny_ablation_results.json)。

## 复现

在已安装项目依赖的环境运行，无需下载模型：

```bash
python -m e3_rm.e3.benchmark --output_dir outputs/tiny-ablation --steps 1500 --seeds 13 42 87
# 额外基线：有效 token 数与渐进 E3 相差不足 0.006%
python -m e3_rm.e3.benchmark --output_dir outputs/tiny-budget-control --steps 5333 --seeds 13 42 87 --methods A_baseline
```

运行器为 [benchmark.py](../e3_rm/e3/benchmark.py)，每完成一次训练便更新输出目录的 results.json。主实验最终检查点固定为第 1500 步，额外基线固定为第 5333 步；不根据测试集挑选模型或种子，不将效果断言写进单元测试。

## 数据、模型与预算

- 数据为“读取记录中的颜色值，按指定单位回答”的合成任务。训练原始 chosen 总采用 Answer 格式、rejected 总采用 Markdown 格式，故意制造非语义捷径；验证和测试的原始格式对半交换。
- 先按来源和颜色/单位组合分层切分，再生成变体：训练 64、验证 32、测试 64 条。每条来源仅属于一个集合。
- 等价变体交换格式、移除装饰；测试额外使用训练中没有出现的 Result 模板。模板解析会核对值和单位不变。
- 语义负样本分别替换值、遗漏单位、替换为错误单位。正确方向由规则产生，正负 sign 均被覆盖，不依赖语言模型自我判定。
- 测试集分母为 64 个原始偏好对、384 个单侧等价关系、192 个双侧变换关系和 192 个语义关系；每类语义变化各 64 个。
- 模型为两层、宽度 48、四头的 GPT-2，约 7 万参数；使用固定语法词表，未使用预训练语义知识。每个种子内，各方法从相同权重出发，保持数据顺序、优化器和训练更新数一致。
- AdamW，学习率 0.001，固定学习率，batch size 8，1500 次更新，最大长度 64；所有组共同使用 0.01 的奖励中心化项，语义 Margin 为 1。B/C/D 只启用对应附加项，E 使用默认三阶段课程，F 从第一步同时启用三个附加项。
- 预算预实验只查看种子 7 的验证集：200 步时 E 的偏好准确率为 50%，1500 步达到 100%，因此在查看正式测试结果前固定 1500 步。正式种子为 13、42、87，共 18 次训练，全部保留。
- 主实验结束后，根据 E 的实际 token 数增加 G 对照：原始基线训练 5333 步，其他条件不变，三个种子均运行；步数由 token 数决定，不根据测试表现选择。总计 21 次对照训练，另有 4 次只查看验证集的预算预实验。原始结果中的 G 是第二条命令所得 A 的别名。

## 独立测试集结果

表中为三个种子的均值 ± 样本标准差。准确率和翻转率以百分数表示；Drift 是模型奖励单位，数值不是概率。

| 组别 | 偏好准确率 ↑ | 扰动翻转率 ↓ | Reward Drift ↓ | 语义敏感性准确率 ↑ |
| --- | ---: | ---: | ---: | ---: |
| A：基础偏好 | 50.00 ± 0.00 | 68.40 ± 2.87 | 7.810 ± 0.167 | 55.56 ± 19.25 |
| B：仅加不变性 | 97.92 ± 3.61 | 1.04 ± 1.80 | 0.225 ± 0.360 | 66.32 ± 8.37 |
| C：仅加差值一致性 | 100.00 ± 0.00 | 0.00 ± 0.00 | 0.288 ± 0.494 | 70.14 ± 17.72 |
| D：仅加语义敏感性 | 50.00 ± 0.00 | 69.27 ± 3.65 | 7.380 ± 0.275 | 87.15 ± 13.52 |
| E：完整渐进 E3 | 100.00 ± 0.00 | 0.00 ± 0.00 | 0.132 ± 0.128 | 91.32 ± 8.36 |
| F：同时启用全部目标 | 97.92 ± 3.61 | 5.56 ± 6.04 | 0.248 ± 0.147 | 91.49 ± 3.14 |
| G：近似等 token 基线 | 50.00 ± 0.00 | 67.19 ± 2.39 | 10.362 ± 0.203 | 44.44 ± 19.25 |

不变性和差值约束明显抑制格式捷径；单独的语义损失提高了语义判别，却未消除原始格式偏置。完整目标同时改善四项指标。E 的平均奖励漂移由基线的 7.810 降至 0.132；用平均绝对偏好分差归一化后，漂移从 0.667 降至 0.021，改善并非仅靠缩小奖励尺度。

## 渐进调度的收益与不足

E 相对 F 的排序与翻转率较好，漂移较低，但语义敏感性略低且种子方差更大；三个种子不足以证明调度全面优越。尤其在“错误单位”这一指令违背子类：

| 组别 | 事实错误准确率 | 条件遗漏准确率 | 指令违背准确率 |
| --- | ---: | ---: | ---: |
| A | 50.00 ± 0.00 | 66.67 ± 57.74 | 50.00 ± 1.56 |
| E | 100.00 ± 0.00 | 100.00 ± 0.00 | 73.96 ± 25.07 |
| F | 95.31 ± 4.69 | 94.27 ± 6.31 | 84.90 ± 10.40 |

E 的种子 87 在指令违背子类仅为 50%；不能用整体 91.32% 掩盖该失败案例。当前结论是完整目标在此受控任务有效，指令敏感性与课程的稳定性仍需验证。

三组平均训练开销：

| 组别 | 实际前向有效 token | CPU 训练秒数 |
| --- | ---: | ---: |
| A | 516,000 | 15.64 |
| E | 1,834,448 | 29.73 |
| F | 2,844,000 | 38.23 |
| G | 1,834,552 | 53.40 |

E 比 F 少处理约 35.50% 的 token。A 与 E 的训练预算仅在优化器更新数上相同，token 数不相同；新增 G 与 E 的有效 token 总数只相差 104，即约 0.0057%，偏好准确率仍为 50%，没有消除格式捷径。这支持本任务的改善并非仅来自增加训练量。有效 token 匹配不等于精确 FLOPs 匹配；计时来自本机两线程 CPU，期间有其他检查运行，不能作为通用吞吐量结论。

## 尚需验证

本实验不覆盖自然语言真实偏好、自动改写质量、7B/14B、下游在线强化学习、QLoRA、DeepSpeed、FSDP 和多 GPU。合成模板与规则具有很强的结构性，样本数和种子数有限。正式实验仍需真实数据、更多随机种子和计算预算匹配的对照。

验证器只保证本实验的有限模板和值/单位规则；项目不提供通用语义等价证明器。实际任务中的格式、长度或装饰变化须另行验证。
